| ----- |
| 1.OBJECTIVES The objective of this test plan is to define the testing strategy and scope for a 2D mobile endless runner game. Testing will focus on verifying gameplay functionality, user interface interactions, scoring, enemy behaviour, player controls, game state transitions, animations, pause functionality and score persistence.. |
| 2.SCOPE The objectives of this testing effort are: Main menu Start Game functionality Exit Game functionality Player controls Jump mechanics Variable jump duration Shooting mechanics Crossbow animation Projectile behaviour Enemy behaviour Enemy destruction Enemy collision Score system Bonus score Best score Game Over Pause menu Resume functionality Return to main menu Ground animation/loop Player running animation Bat flying animation UI functionality Game state transitions	 |
| 3.TEST STRATEGY The testing will include the following tests: Functional testing : validated that each feature works according to the specified requirements. UI testing : Ensure that interface elements such as buttons,text, positions and interfaces works according to the specified requirements Gameplay testing: Ensure the following functions works according to the specified requirements jump shooting enemies collisions score High score Start menu Game over Boundary / Edge Case Testing :Try the gameplay functionalities trying to find if there are errors on each small detail, to ensure the functions works according to the specified requirements The delay on the jump The fire rate of the weapon The pause function while there are moving objects on scene Test the score and high score on multiple boundary tests Try to open menus while there are other open  |
| 4.TEST ENVIRONMENT Component Configuration Engine Unity Platform Android Device Honor 70 lite OS 14 Build 1.0.0 Input touchScreen  |
| 5.ENTRY CRITERIA Testing will begin when: Build successfully installed. Application launches successfully. The main menu is accessible. The test build is stable enough for execution. A test environment is available.  |
| 6.EXIT CRITERIA The testing will be considered completed when: 100% of planned test cases executed. All Critical and High severity defects resolved or accepted. No blocking issues remain. Regression testing completed. Test summary report completed.  |
| 7.DELIVERABLES The following documents will be produced during the testing process: Test Plan Test Cases Test Execution Results Bug Reports Requirements Traceability Matrix Test Summary Report Test Evidence  |
